This directory contains simulation/training data and/or PyTorch models that are hosted separately at

Negedly, M. (2026). Supplementary data for "Correlation-Free Transition Path Sampling through Shooting Point Generation Guided by Committor Learning" [Dataset]. Zenodo. DOI: [10.5281/zenodo.22875161](https://doi.org/10.5281/zenodo.22875161)

# Steps to extract the relevant data
1. Download the file `wolfe_quapp.7z` from the above citation
2. Extract the file using
```bash
# After installing the package 7zip for your distribution
$ 7z x wolfe_quapp.7z
```
3. Move the contents of the sub-directory `wolfe_quapp/wq_tps_normal` into this directory
